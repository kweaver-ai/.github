KWeaver 项目以 [**KWeaver Core**](https://github.com/kweaver-ai/kweaver) 与 [**KWeaver DIP**](https://github.com/kweaver-ai/kweaver-dip) 为核心。

[**KWeaver Core**](https://github.com/kweaver-ai/kweaver) 面向企业决策智能体，采用 harness-first 思路：将分散的数据、知识、工具与策略转化为可治理的上下文、可安全执行的动作与可验证的反馈闭环；结合语义建模、实时接入、运行时管控与 TraceAI，帮助 AI 在复杂企业环境中可靠地推理、适应与行动。**KWeaver Core 为纯后台框架，不提供可访问的界面。** **若需要界面访问，请安装 [KWeaver DIP](https://github.com/kweaver-ai/kweaver-dip)。**

[**KWeaver DIP**](https://github.com/kweaver-ai/kweaver-dip) 是用于开发与管理数字员工的 AI 原生平台，依托业务知识网络，让企业智能可理解、可执行、可治理。KWeaver DIP 是基于 KWeaver Core 开发的。
